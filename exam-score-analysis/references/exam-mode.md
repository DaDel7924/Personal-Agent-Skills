# 考试类型判定与两种模式

不是每次考试都有外校成绩。**判断错模式，后面全错**：把单校考试当联考做，会去找不存在的基准、硬编一个名次分母；把联考当单校做，会白扔掉最有价值的校际对比。

## 一、Step 0 第一件事：判定数据形态

三条判据，**任一成立即视为有外校数据**：

| 判据 | 怎么查 |
|---|---|
| ① 存在"各校对比"类目录 | `**/2.各校成绩分析/各项指标对比/*`、`各校成绩*`、`*校际*` |
| ② 指标表含多校数据行 | 表内有"学校/参评校"列，且数据行 ≥2 所 |
| ③ 一分一段人数远大于本校考生数 | 一分一段累计人数 / 本校人数 > 1.5 |

本校人数从 `1.学生榜单/年级学生榜单/*` 或班级成绩表统计。

## 二、三种数据形态与可用步骤

| 形态 | 特征 | 可用步骤 | 不可用 |
|---|---|---|---|
| **A 完整联考** | 有 N 校指标表 + 联考一分一段 + 本校学生级榜单 | ① 校际对比 ② 班级 ③ 学生分层 ④ PPT ⑤ 核对 | —— |
| **B 联考仅汇总** | 有 N 校指标表，但**无外校学生级数据** | ① 校际对比（用均分与人数加权） ② 班级 ③ 学生分层 ④ PPT ⑤ 核对 | 外校逐生对比、外校分数段分布 |
| **C 单校考试** | 只有本校成绩，无任何外校数据 | **从 ② 开始**：② 班级 ③ 学生分层 ④ PPT ⑤ 核对 | ① 校际对比；联考口径上线测算 |

形态 B 是最常见的误区：外校只有均分也能做校际对比（用 `Σ(均分×人数)/Σ人数` 加权），只是不能做外校逐生分析。不要因为它"不完整"就整段砍掉①。

形态 C 时，**明确告知用户"本次无外校成绩，不出现任何校际分差与联考名次"**，并按第四节的替代口径执行。

## 三、参评校数 N 不写死

- N 由数据自动统计：指标表"学校"列去重计数，或"整体"行以外的数据行数。
- 名次写作 `x/N`，N 在生成时从数据取，不写常量。
- 各科 N 可能不同（某科有校缺考）——按该科实际有考生的校数计，脚注写明。
- 交付物里出现的"N 所参评校"必须与当次数据一致；换考试重新取，不复用上次的值。
- 参评校少于 5 所时，在口径页提示"参评校过少，名次与分差的解释力有限"。

## 四、形态 C（单校）的口径替换

| 维度 | 联考模式 | 单校模式替代 |
|---|---|---|
| 基准 | N 校全体考生加权均分 | **本校年级均分**（分方向）；班级表则用班级均分 |
| 分差 | 本校 − 联考基准 | **与年级均分差**（班级）、**与上次考试差**（环比） |
| 名次 | x/N | **年级名次**（x/本校人数）、班级名次、单科名次 |
| 超均率 | 分差 / 联考基准 | 改为**得分率**（均分/满分）与**距年级均分率**，不再叫超均率 |
| 贡献率 | 该科分差占总分差比例 | 保留，但含义变为"该科对总分的算术贡献"，不可用于跨校解释 |
| 赋分判断 | 看 N 校最低分是否 ≥30 | 看**全校该科最低分**是否 ≥30 且集中；判据同（赋分起点 30） |
| 上线 | 联考一分一段定位 | 见下 |

### 单校模式的上线测算（三选一，必须标注性质）

1. **历史划线折算**（首选）：用上届高考特控/本科线按当年难度系数折算本次分数，标注"按上届划线折算，非本次官方划线"。
2. **校内百分位**：如"年级前 X% 视为本科希望"，X 取上届实际录取率。标注"校内模拟，仅用于内部动员"。
3. **目标分制**：学校自定目标分（如物理类本科目标 400 分），逐生统计达标。标注"学校自定目标，非划线"。

三种都不得写成"本科线""特控线"，统一写"校内模拟线"，并加"不得对外引用"。

**不要**在没有外校数据时编造一分一段表，或用本校分布冒充联考分布。

### 单校模式的 PPT 章节

```
1 年级整体   参考人数、九科均分与得分率、与上次环比、分数段分布
2 各班情况   班级总分三次对比、九科逐科（含教师）、班际差异
3 学生分层   前 N 名分布、临界生、短板诊断
4 归因与措施
```

与联考版相比：删掉"总分排名与联考分差"整章（含名次、分差、超均率三列），第一章改为"年级整体与环比"；其余章节结构不变。页数通常 20–24 页。

## 五、单校模式的核对：改用内部恒等式

联考模式有外部锚点（N 校指标表、一分一段表）可交叉验证。**单校模式没有外部锚点**，全靠内部一致性，必须逐条验：

1. **人数闭合**：各科有效人数 ≤ 参考人数；班级人数之和 = 年级人数（差额须能解释为缺考/转入）。
2. **总分闭合**：各科均分 × 满分占比之和 ≈ 总分均分（赋分科目按赋分后计）。
3. **加权闭合**：Σ(班级均分 × 班级人数) / 年级人数 = 年级均分（容差 0.005）。
4. **排名闭合**：前 N 名名单人数 = 表内计数；同分并列须使实际人数 ≥ N。
5. **环比闭合**：（本次均分 − 上次均分）× 人数 与总分变化量一致。
6. **赋分闭合**：赋分后均分应高于卷面均分，且高于幅度与该科难度一致（真实案例 +14 ~ +31 分）。

这六条跑通，单校分析的可信度等同于联考的逐格核对。任何一条不闭合，先查过滤条件（见 `data-pitfalls.md` 第 2 条）。

## 六、模式判定写进开工确认单

```
■ 考试类型
  A 完整联考 / B 联考仅汇总 / C 单校考试
  判据：<命中的判据>
  参评校数 N = <N>（各科：语文 N、数学 N …）
  可用步骤：①②③④⑤ 或 ②③④⑤
  本次不出现：校际分差 / 联考名次 / 联考一分一段
```
