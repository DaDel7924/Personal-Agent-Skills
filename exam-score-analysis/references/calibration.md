# 口径锁定清单

Phase 0 的唯一产出：一张用户签字确认的口径表。本文给出每一项的判定依据、常见分歧与推荐表述。

## 为什么会返工

统计口径是**不可推导的**，只能由业务方拍板。同一个数据包在不同口径下可以得出方向一致但幅度差一倍以上的结论（真实案例：物理分差加权口径 −76.96，简单平均口径约 −46.5）。因此任何"我先按常规算"的行为都会导致后续全量重做。

## 七个必锁项

### 1. 校际基准

| 选项 | 算法 | 特性 |
|---|---|---|
| A 全部考生加权 | 指标表"整体"行（该科全体考生加权平均） | 与教务系统一致，大校权重高，基准被抬高 |
| B 参评校均分简单平均 | 各校均分求算术平均 | 每校一票，小校权重被放大 |
| C 剔除本校 | 排除后重算 | 用于"如果对标兄弟校"的假设场景 |

推荐 A，并在口径页注明 B 的结果方向（"简单平均口径下分差会缩小，方向一致、幅度不同"）。**不要**在正文里混用 A 与 B 的数字。

### 2. 排名分母

看指标表名次列的原始定义。两种常见口径：

- 参评校总数（N，由数据统计，不写死）——本校在任何科目都排 `x/N`；
- 该科有考生的校数——缺考校使分母降到 29 甚至更少。

不要自行重排。若重排，必须与源表逐校对齐验证。**排名与分差不同向是正常现象**（全员都低的科目分差大但名次好），写结论时要区分"绝对提分"与"相对追赶"两种策略含义。

### 3. 上线基数与划线

优先级：

1. **官方公布名次**（最权威）——由名次在一分一段表反查分数；
2. 联考全体考生基数 × 比例——须标注为推算；
3. 本校考生基数 × 比例——最小样本，通常不采用。

细线（本科线）若无官方值，可用位次比对齐：`本科位次 = 特控位次 × (本科比例/特控比例)`，比例取官方公布值。真实案例用 `特控名次比 1.654`（物理 5372/3248）对齐历史方向本科线。

**所有推定值必须标注"不得对外引用"**，并写入 PPT 口径页与 Excel 说明页。教研院未公布官方划线时，这是免责的唯一防线。

### 4. 赋分科目处理

三种量纲不可混：

- 赋分后（跨校可比的唯一量纲，起点通常 30、上限 100）；
- 卷面原始分（仅校内可比，用于环比"教学是否进步"）；
- 两者并列（推荐）。

呈现建议：表格列"9月卷面 / 10月卷面 / 期中卷面 / 期中赋分"，环比用卷面（衡量教学），与联考差用赋分（衡量位次）。表头必须写清"卷面"二字，否则用户拿 Excel 的赋分列一对就发现"对不上"。

### 5. 年级均分聚合

| 口径 | 算法 | 用途 | 特征 |
|---|---|---|---|
| 学生加权 | Σ(分数)/Σ(人数) | 校际对比 | 大班权重高 |
| 班级算术平均 | 各班均分求均值 | 班级横向比较、环比 | 每班一票 |

同一年级的"数学均分"在两套口径下可差 1.5 分（真实案例 51.47 vs 50.01）。**两个交付物各写各的口径，并在两边说明页互相点名**，禁止跨文件相减。

### 6. 前 N 名口径

- 绝对名次（如年级前 50/100）——须声明"含同分并列"，并列会使实际人数超过 N；
- 比例折算（如前 15%）——须声明基数。

不同科目考生池不同（语数外为全体，选考科目为选考者），跨科比较前 N 人数时必须换算占比，不能直接比绝对数。

### 7. 交付物清单

先定清单再动手，典型四件套：

1. 校际对比汇总（总分排名 / 九科对比 / 分方向单科 / 科目贡献率）；
2. 班级层面分析（班级总分三次对比 + 九科分班表）；
3. 学生分层（潜力生分档 / 临界生 / 上线名单）；
4. 汇报 PPT。

清单变更（如"再加一页短板诊断"）时，先评估连带影响页，再动手。

## 口径变更的标准动作

用户中途改口径时，**不要直接改数**，按顺序：

1. 列出受影响清单：哪几张工作表、哪几页 PPT、多少个单元格；
2. 备份当前版本；
3. 改计算 → 重跑独立核对 → 逐格 diff 证明"只改了这几处"；
4. 在 run-log 记录变更原因与新 `sha256`；
5. 检查旧值残留：全稿扫描被作废的数值（如旧分数线 441.0/501.5/424.0），一处不漏。

## 口径页模板（Excel 说明页 / PPT 末页共用）

```
1. 校际基准：N 所参评校该科全体考生加权平均（指标表"整体"行），非校均分简单平均。N 随当次考试变化。
2. 分差 = 本校均分 − 联考基准；超均率 = 分差 / 联考基准。
3. 名次分母：该科有考生的参评校数。
4. 再选科目（化/生/政/地）为等级赋分，起点 30、上限 100；跨校对比一律用赋分。
5. 合并基准为按各科实际考生数加权自算值，非表内原值。
6. 参评校以市属学校为主，本校为唯一<地区>学校，名次不等于全省位次。
7. 本科线为推定值（按位次比对齐），特控线按官方公布名次换算；均不得对外引用。
8. 班级均分为各班算术平均，与校际对比的学生加权口径不同，不可混用。
```
