# PPT 规范

## 一、总体策略：先问模板，两条工艺

**动手前必须明确有没有可参考的模板。** 有模板与无模板是两条不同的工艺，不可混用。

| 分支 | 条件 | 工艺 | 主要风险 |
|---|---|---|---|
| **A 有模板** | 用户给出上一次同类会议的 pptx | 复制为母版，继承母版、版式、主题字体与配色，只换文字与表格 | 内容量超出原版式容量（原 8 行、本次 15 行），需拆表而非缩字号 |
| **B 无模板** | 明确没有，或只有 PDF/截图/口头描述 | 按本文第五节从零设计，先出 2 页样张确认再批量生成 | 自建版式最容易被否，样张是唯一低成本纠错点 |

教师会材料的第一要求是"看起来和上次一样"。分支 A 下任何"我认为换个颜色更好看"的改动都属于越界。

## 二、页面结构与顺序

```
封面 1 → 章节页 4 → 正文 20 → 结束 1 → 口径页 1      （联考，共 27，可扩至 30）
封面 1 → 章节页 4 → 正文 16 → 结束 1 → 口径页 2      （单校，共 24）
```

四个章节对应四层追问，顺序不可调换：

1. **学校整体** —— 差多少（总分排名、九科分差、贡献率）；单校改为"年级整体与环比"
2. **各班情况** —— 差在哪个班哪个科（班级总分三次对比 + 九科逐科）
3. **学生分层** —— 哪些人还能救（分档、逐生距线、临界生、短板诊断）
4. **归因与措施** —— 下一步怎么做

章节页只放标题，不写摘要——教师会需要它作为"换气口"。

## 三、单张数据页的固定结构

四个区块，缺一不可：

```
[标题]                                    [右上：口径说明 + 参照值]
[表格主体]
[结论：1–3 行，带具体数字]
```

- **右上口径说明必须含参照值数值**。写"与联考差 = 本班均分 − N 校该科均分（语文 101.53 / 历史 100.03）"，不要只写公式。用户第一个问题永远是"这个差是跟谁比"。
- **表格字号**按行数与列数自适应：9–11 列、13 行时约 10.5–11pt；超过 14 行必须拆成左右两表。
- **结论必须有数字**。"数学和英语是主要短板"不合格；"数学 −18.65、英语 −15.57 为最大短板，两科合计占总分差 46.85%"合格。

## 四、分支 A：沿用既有模板

| 元素 | 处理 |
|---|---|
| 母版与版式 | 全盘继承，不新建 layout |
| 标题条 | 沿用原宽度与填充色（常见 486–490×73，填充 `#9DBFF7`，文字 `#002060` 楷体） |
| 表头 | 沿用原填充（常见 `#7CDED7`），宋体，居中 |
| 表格边框 | 黑色 1px，全框线，居中 |
| 正负值 | 负值红、正值绿 |
| 新增页 | 复用最接近的已有 layout；若原为图片页而本次要放 15 行表，改用表格 layout，不要在原图上盖表 |

## 五、分支 B：无模板时从零设计

这套参数在真实校情材料上迭代过，可直接用；拿到校徽与主色后按第 2 步替换主色即可。

### 1. 画布与栅格

- 画布 16:9，`Inches(13.333) × Inches(7.5)`（EMU 12192000×6858000）
- 左右留白 0.5in，上下留白 0.45in / 0.4in，内容区宽 12.33in
- 栅格按 12 列切，列间距 0.12in；左右双表各占 6 列

### 2. 配色（单主色 + 语义色，不做渐变）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色（标题、强调） | `#002060` | 深蓝，稳重，投影不刺眼 |
| 辅色（标题条底） | `#9DBFF7` | 主色浅调，避免大面积深色压字 |
| 表头填充 | `#7CDED7` | 青绿，与主色同明度层，不抢视觉 |
| 正文 | `#262626` | 不用纯黑，投影更柔和 |
| 分隔线 / 表格边框 | `#BFBFBF` | 0.75pt |
| 负值（差） | `#C00000` | 中国习惯：差为红 |
| 正值（好） | `#1B7F3B` | 好为绿 |
| 关键结论底色 | `#FFF2CC` | 浅黄，全篇不超过 3 处 |
| 页面背景 | `#FFFFFF` | 白底，便于打印 |

学校有指定主色时，只替换"主色"与"辅色"两行，语义色不动——语义色表达含义，不参与品牌。

### 3. 字体层级

| 层级 | 字号 | 字重 | 字体 |
|---|---|---|---|
| 封面主标题 | 40–46pt | 加粗 | 黑体 / 思源黑体 |
| 封面副标题（日期、单位） | 18pt | 常规 | 宋体 |
| 章节页标题 | 54–66pt | 加粗 | 楷体 / 思源宋体 |
| 页标题 | 26–28pt | 加粗 | 黑体 |
| 右上口径说明 | 10.5–11pt | 常规 | 宋体 |
| 表头 | 11pt | 加粗 | 黑体 |
| 表格正文 | 10.5–11pt | 常规 | 宋体 |
| 结论 | 14–15pt | 关键数字加粗 | 宋体 |
| 页脚（注、来源） | 9pt | 常规 | 宋体 `#808080` |
| 数字 | 与正文同号 | —— | Times New Roman（等宽，便于按位对齐） |

### 4. 四种版式的骨架（坐标以 1280×720 计）

**封面**：校徽居中上方（y≈100，高≈90）；主标题两段式（y≈240、300），避免在"联考""分析"处断行；副标题单位与日期（y≈420）。

**章节页**：仅标题，垂直居中偏上（y≈300），左侧加一条 6×120 的主色竖线作为章节标记。

**表格页**（主力版式）：

```
y=24   ┌ 页标题 28pt ────────────────────┐  ┌ 右上说明框 x=880..1232 ┐
y=72   └──────────────────────────────────┘  └ y=24..120，10.5pt 灰 ┘
y=136  ┌ 表格主体（最多 14 行） ────────────────────────────────┐
       │ 表头 y=136..168（行高 0.32in）                          │
       │ 数据行 y=168..600                                       │
y=600  └─────────────────────────────────────────────────────────┘
y=604  ┌ 结论区 14pt（高度按剩余空间自适应，最多 3 行） ┐
y=680  └ 页脚 9pt 灰 ─────────────────────────────────┘
```

**结束页**：居中"谢 谢"（44pt），下方一行日期或单位。

### 5. 表格样式

- 表头：填充 `#7CDED7`，黑体加粗 11pt，居中，行高 0.32in
- 数据行：行高 0.28in，斑马纹 `#F7F9FC`（隔行浅底），全框线 0.75pt `#BFBFBF`
- 对齐：文字列居中；数值列右对齐（小数点对齐）；名次列居中
- 负值红、正值绿；`0` 与空值保持中性灰
- 列宽按内容分配，最短列不低于 0.8in，最长列不超过 3.2in

### 6. 图表（如需要）

- 只用一主色 + 灰对比色，无 3D、无渐变、无阴影
- 条形图按值降序排列，轴标签直接写班级/科目，不用图例
- 数据标签 10pt，放在条端；零值不标
- 一张图最多 12 个类别，超出改用表格

### 7. 交付前的版式自检（8 条）

1. 每页只有一个视觉重点（标题 > 表格 > 结论，不互相抢）
2. 主色出现频次不超过 3 处/页（标题、竖线、强调数字）
3. 全篇强调底色 ≤3 处
4. 同一区块内不超过 3 种字号
5. 表格不越界、不压页脚、不缩字号强塞
6. 数字全部两位小数（人数为整数），单位一致
7. 负值红/正值绿无遗漏，`0` 未被误染色
8. 封面、章节页、表格页、结束页四类版式风格统一，不混搭

### 8. 与分支 A 的关系

自建版式完成后，若用户后续提供了学校模板，下一期应改用模板（分支 A），**不要**把自建版式固化成"学校风格"——它只是这一次的兜底。

## 六、数值与文案规则

1. **全部两位小数**，包括结论句中的百分比（`46.85%` 而非 `46.9%`）与分值（`76.96` 而非 `77.0`）。混用位数会引发"和 Excel 对不上"的质疑。
2. **人数整数**，不得出现 `39.0`。
3. **区间写清开闭**：`−15（含）至 −10（不含）分`。模糊写法会导致边界学生归属争议。
4. **推定值必须标注**：`本科线为推定值；特控线按官方公布名次换算`。避免"自主划线"这类容易被理解为学校随意定的措辞。
5. **不写无数据支撑的因果**。"物理贡献率低所以在总分结构中被低估"是错的——贡献率低正是低分的算术结果。只陈述可核算的事实。
6. **对比必须同向**。分差与名次不同向时（分差最大但名次最好），要显式说明原因，否则会被质疑数据错误。

## 七、口径页（末页）

表格形式，8–10 行，每行"项目 | 说明"。必须覆盖：

1. 考试类型与可用范围（联考/单校）
2. 校际基准算法（加权，非校均分简单平均）
3. 分差与得分率定义
4. 名次分母（N 或本校人数）
5. 赋分说明（起点 30、上限 100）
6. 合并基准为自算值
7. 两套均分口径差异（学生加权 vs 班级算术平均）
8. 划线性质（官方/推定/校内模拟）
9. 数据来源与截取时间

## 八、技术实现

### 新建
用 python-pptx 从空白 presentation 建，或复制母版后逐页 `add_slide(layout)`，表格用 `shapes.add_table`。表格行高按内容估算，宁可留白也不要越界。

### 改写已有 pptx 的文字
```python
# 正确
p = shape.text_frame.paragraphs[0]
run = p.add_run()
run.text = "新文本"
run.font.size = old.size          # 复制原 run 的 rPr 属性
run.font.bold = old.bold
run.font.name = old.name

# 错误：会插到 <a:endParaRPr> 之后，PowerPoint 整段不渲染
p._p.append(new_r_element)
```

### 改完的验证
1. 页数、shape 数、每个 shape 的 `left/top/width/height` 与改前逐一致（证明没动版式）；
2. 文本片段数变化量 = 预期改动量（如"2216 个片段仅 1 处变化"）；
3. 逐页渲染截图或整稿 overview 通读；
4. 抽读改动页，确认新文本真的出现了（不是空白）。

## 九、整稿通读必查清单

- 封面标题断行是否在词中间；
- 标题条文字是否贴边（条宽不足）；
- 结论框是否压住表格或超出页面；
- 单表行数是否超过 14 行（需拆表）；
- 标题与右上说明是否重叠；
- 结论中被点名的班级/学生是否与数据一致（最高班/最低班最易写错）；
- 人数与班级数是否为动态统计而非硬编码；
- 右上说明的参照值是否与该页表格一致（换页后忘改是本类最高频错误）。
