# 开工问询（拷问清单）

Step 0 的唯一产出：一份用户确认过的**开工确认单**。没有确认单不开工。

## 一、问询原则

1. **一次问完**。把 6 项必问 + 7 项口径放在同一轮，不逐条挤牙膏——每条问一次就多一轮往返，用户会烦。
2. **每问给推荐值**。形式是"我建议 X，因为 Y，同意吗"，而不是"你想怎么做"。用户答"你决定"时按推荐值执行，并在确认单上标注"我按默认取"。
3. **不猜数据位置**。宁可问一句"数据包是不是在 Downloads"，也不要全盘搜索。搜到了也只读，不移动。
4. **缺什么就砍什么**。数据不支持的分层不做，并在交付时明说"这一步因缺学生级数据未做"，而不是用汇总表凑一个近似结果。

## 二、必问 6 项（第 0 项决定后面问什么）

### 0. 这次是联考还是只有本校（最先问）

**不是每次考试都有外校成绩。** 这一问的答案决定后面四问问什么、以及整条流水线走五步还是四步。

不要只靠用户口述——口述往往记错（"应该是联考吧"）。按三条判据自查一遍，再请他确认（详见 `exam-mode.md`）：

| 判据 | 怎么查 |
|---|---|
| ① 有"各校对比"类目录 | `**/各校成绩分析/各项指标对比/*`、`*校际*` |
| ② 指标表含多校数据行 | "学校"列去重 ≥2 所 |
| ③ 一分一段人数 ≫ 本校人数 | 比值 > 1.5 |

| 用户说 | 自查结果 | 处理 |
|---|---|---|
| "是联考" | 找到 N 校指标表 | 形态 A/B，走①②③④⑤ |
| "是联考" | 找不到外校数据 | 以数据为准 → 形态 C，告知用户"数据包里没有外校成绩，本次按单校分析" |
| "只有我们学校" | 确实无外校 | 形态 C，从②起，全篇不提校际 |
| "记不清" | 自查判定 | 把判定结果和依据摆给用户确认，不替他猜 |

形态 C 时立刻说明三件事：① 不做校际对比；② 没有联考名次与联考划线；③ 上线改用校内模拟线。**先说清楚，避免做到一半被追问"我们排第几"**。

### 1. 原始成绩数据在哪

要问到的粒度：

- 目录绝对路径；
- 数据包结构：有没有 `1.学生榜单/年级学生榜单/*.xls`（学生级）、`2.各校成绩分析/各项指标对比/*.xlsx`（各校指标，N 校）、`分数段分布/一分一段表`（定线）；
- 有几个方向（物理类/历史类各一套？）；
- 本次是第几次考试，前两次的榜单在不在一起（决定能不能做三次环比）；
- 是不是首次拿到该数据包（首次需要先跑 Phase 1 体检）。

典型回答与处理：

| 用户说 | 实际含义 | 处理 |
|---|---|---|
| "在下载文件夹里" | 未整理，可能多层嵌套 | 用 `Glob` 找 `*共性分析*` / `*指标对比*`，确认后只读引用 |
| "只有汇总表" | 无学生级数据 | 砍掉步骤③（分层/上线/临界生），只做①②④ |
| "和上次一样的地方" | 路径沿用 | 先读项目记忆里的路径常量，向用户复述一遍确认 |
| 给了网盘/在线文档 | 需先落地 | 先下载到本地工作目录，再开始 |

### 2. 有没有可参考的 PPT 模板

要问到的粒度：

- 上一次同类会议的 pptx **绝对路径**（不是"上次那个"，要具体文件）；
- 是否要求页数与上次一致；
- 是否有必须保留的视觉元素（校徽、封面弧线、章节页字体）。

**这一问决定 PPT 的整条工艺，必须问出结果，不能含糊过去。**

| 回答 | 走哪条 | 后续动作 |
|---|---|---|
| 给了 pptx 路径 | 分支 A 复用 | 复制为母版，只换文字与表格，不改配色与版式 |
| 明确没有 | 分支 B 自建 | 按 `ppt-spec.md` 第五节从零设计；**先出 2 页样张（封面 + 一张表格页）确认，再批量生成** |
| 只有 PDF/截图 | 看情况 | 能提取配色与版式规律的，按 B 复刻；只有零散截图的，按 B 自建 |
| "你看着办" | 按 B 处理 | 但必须再问三件事：学校全称与简称、有无校徽图片、学校有无惯用主色 |

自建的兜底参数：1280×720（16:9）、四章节结构、主色 `#002060` + 标题条 `#9DBFF7` + 表头 `#7CDED7`、黑体标题宋体正文、负值红正值绿。完整参数见 `ppt-spec.md` 第五节。

**别做完 30 页才被否。** 样张是自建工艺唯一的低成本纠错点。

典型回答与处理：

| 用户说 | 处理 |
|---|---|
| "用上次 10 月考的那份" | 复制该 pptx 为母版，继承 slide_master / layout / 主题字体，只换文字与表格 |
| "没有模板，你看着办" | 用默认版式，但先出 2 页样张确认 |
| "用学校的统一模板" | 要文件路径；学校模板常带固定母版，不可改 |
| "参考这个 PDF/图片" | 提取配色与版式规律，用 python-pptx 复刻，不直接嵌入位图 |

### 3. 产物存哪个文件夹

推荐：`<工作区>/成绩分析_YYYYMMDD/`，下设 `01_校际对比/ 02_班级分析/ 03_学生分层/ 04_汇报PPT/ _过程/`。

必须问清的三点：

- 是否要覆盖工作区根目录的旧文件（覆盖前必须备份）；
- 是否要放到共享盘/桌面（供他人取用）；
- 文件名是否要带日期（建议带，`高三年级上学期期中考试成绩分析_20261116.xlsx`）。

目录确定后**全程不搬家**：审计脚本、PPT 数据提取脚本里都是绝对路径，搬一次全部失效。

### 4. 交付哪几件

五件套勾选：校际对比 / 班级分析 / 学生分层 / PPT / 附录（逐生名单）。

默认全做。用户只要 PPT 时，仍建议先出 Excel——PPT 的每个数字都必须能回溯到表，没有表就没有核对基线。

### 5. 七项口径

见 `calibration.md`。问法示例：

> 基准我建议用 N 校全体考生加权（指标表"整体"行），不是 N 校均分的简单平均——后者会让分差看起来小一半。名次沿用表内原列，分母是"该科有考生的校数"，脚注会写明。这两项按此执行？

## 三、开工确认单模板

问完后输出这张表，等用户回"确认"再动手。表格直接贴进对话，不建文件。

```
【开工确认单】<考试名称> 成绩分析

■ 考试类型
  联考 A / 联考仅汇总 B / 单校 C      判据：<命中的判据>
  参评校数 N = <N>（各科：语文 N、数学 N …）；单校填"仅本校 <人数> 人"
  可用步骤：①②③④⑤ ｜ 本次不出现：校际分差 / 联考名次 / 联考一分一段

■ 数据
  原始包：<绝对路径>
  含：学生级榜单 ✓/✗ ｜ 各校指标表（N 校）✓/✗ ｜ 一分一段 ✓/✗ ｜ 往次榜单 ✓/✗
  方向：物理类 / 历史类

■ 交付
  ① 校际对比（总分/九科/贡献率）
  ② 班级三次考试分析
  ③ 学生分层（<档位定义>）
  ④ PPT（<页数>页，工艺：A 复用模板 <pptx路径> / B 自建版式，样张已确认）
  ⑤ 核对报告

■ 口径（7 项）
  基准 / 名次分母 / 划线 / 赋分 / 聚合 / 前N / 边界

■ 产物目录
  <绝对路径>

■ 预计不做
  <因数据缺失或单校模式而砍掉的步骤，逐条列出>
  <若为单校：校际对比整章、联考名次与分差、联考划线>

确认后开工。改动任一项请直接指出。
```

## 四、用户回答模糊时的处理

| 模糊回答 | 追问方式 |
|---|---|
| "你看着办" | 给出推荐值 + 一句理由，请求"回个'行'即可" |
| "差不多就行" | 明确说出差异量级（"两种口径分差差 30 分，报告里写哪个？"） |
| "上次怎么弄的" | 读项目记忆 / run-log 复述上次口径，请其确认沿用 |
| "先用这个，后面再改" | 接受，但在确认单标注"口径待定，改动将触发全量重算"，并先做可复用部分 |
| 不回答口径问题直接催进度 | 用推荐值开工，**在交付物说明页第一行**写明所用口径与"未经确认" |

## 五、什么时候可以跳过问询

只有一种情况：用户在同一轮里已经把 6 项全部说清（考试类型、数据路径、模板、目录、交付件、口径）。此时把确认单**复述一遍**即可开工，不必再问。

任何一项缺失，都要问。省一轮问询换来一次全量重做，是本类任务最典型的亏本交易。
