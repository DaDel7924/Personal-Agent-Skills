# 联考成绩分析流水线

面向中学教研室/教务处的多校联考分析任务。本技能的核心不是"算得快"，而是**口径一次锁定、结论可逐格回溯**。

## 为什么需要这套流程（血泪前提）

同类任务最常见的失败不是算错，而是：

1. **口径反复变更**导致全量重做。真实案例：上线基数改了 3 次（本校基数 → 联考全体比例 → 官方公布名次），每改一次牵扯 3 份 Excel + 30 页 PPT + 约 1.1 万项复核，整条流水线重跑 7 轮。
2. **数据源版本漂移**。同一天内工作簿被重生成 4 次（新增列、改列序、加工作表），每次都要重新提取、重新比对。必须用"结构指纹"而非行号定位。
3. **结论文字与数据表不同源**。表格由脚本算出、结论由人写，二者一旦分头维护就会写出"13 个班全部高于 10 月"（实为 12 个）、"物理贡献率最低"（实为第 6）这类硬错，且只有人工通读才能发现。

因此本技能强制三件事：**Step 0 开工问询**（先判联考/单校，再问数据在哪、有无模板、产物放哪）、**Phase 0 口径锁定**、**Phase 5 独立核对**。三者都不可跳过。

## 执行顺序

```
Step 0 开工问询(阻塞)
   └─ 先判模式 ─┬─ 联考 → 五步全流程 ①②③④⑤
                └─ 单校 → 从第②步起 ②③④⑤
Phase 0 口径锁定(阻塞) → Phase 1 数据体检 → Phase 2 计算
→ Phase 3 Excel → Phase 4 PPT → Phase 5 独立核对 → Phase 6 留痕
```

Step 0 与 Phase 0 未完成不得开始计算；Phase 5 未通过不得交付。

### 先判模式：联考还是单校

**不是每次考试都有外校成绩。** 判断错模式，后面全错——把单校当联考做，会去找不存在的基准、硬编一个名次分母；把联考当单校做，会白扔掉最有价值的对比。

三条判据，任一命中即为有外校数据（详见 `references/exam-mode.md`）：

| 判据 | 查什么 |
|---|---|
| ① 有"各校对比"类目录 | `**/各校成绩分析/各项指标对比/*`、`*校际*` |
| ② 指标表含多校数据行 | 有"学校/参评校"列，去重 ≥2 所 |
| ③ 一分一段人数远大于本校 | 一分一段累计人数 / 本校考生数 > 1.5 |

| 形态 | 特征 | 可用步骤 |
|---|---|---|
| **A 完整联考** | N 校指标表 + 联考一分一段 + 本校学生级榜单 | ①②③④⑤ |
| **B 联考仅汇总** | 有 N 校均分，无外校学生级数据 | ①②③④⑤（①用均分×人数加权） |
| **C 单校考试** | 只有本校成绩 | **从②起**：②③④⑤ |

形态 C 时明说"本次无外校成绩"，全篇不出现校际分差、联考名次、超均率；改为与年级均分差、与上次考试环比、得分率。上线改用校内模拟线（历史划线折算 / 校内百分位 / 目标分制，三选一，必须标注性质）。

### 交付步骤 ↔ 七个阶段

联考模式五步，单校模式四步；七个阶段是"纵向流水 + 横切门禁"：

| 任务步骤 | 联考 | 单校 | 覆盖阶段 | 产出 |
|---|---|---|---|---|
| ① 校际对比核算 | ✓ | — | Phase 1 + 2 | N 校总分/九科/贡献率 |
| ② 班级分析 | ✓ | ✓（首步） | Phase 3 第二册 | 班级总分 + 九科分班 |
| ③ 学生分层 | ✓ | ✓ | Phase 3 第三册 | 分档 + 逐生距线 + 短板 |
| ④ 汇报 PPT | ✓ | ✓（章节结构不同） | Phase 4 | 20–30 页成稿 |
| ⑤ 全面核对修正 | ✓ | ✓（改用内部恒等式） | Phase 5 | 核对报告 + 修正 |
| —— 横切门禁 | 适用 | 适用 | Phase 0、Phase 6 | 口径表、run-log |

**参评校数一律记作 N**，由数据统计得出（指标表"学校"列去重，或"整体"行以外的数据行数），名次写 `x/N`，不写常量。各科 N 可能不同（有校缺考该科），按该科实际有考生的校数计并加脚注。参评校少于 5 所时提示"名次与分差解释力有限"。

**不要**把 Phase 0/5/6 当成第 6、7 步去交付——它们在每一步都要用：口径在动手前锁、核对在每步产出后轻量跑、留痕在每次改动后写。

## Step 0 开工问询（阻塞，必问）

**未完成本步不得读数据、不得写代码。** 一次问完，不逐条挤牙膏；每问给出推荐值，用户答"你决定"时按推荐值执行并显式记录。

### 必问 6 项（第 0 项决定后面问什么）

| # | 问题 | 为什么必问 | 缺失时的处理 |
|---|---|---|---|
| 0 | **这次是联考还是只有本校？** 有没有外校成绩？ | 决定做不做①，以及全部基准与上线口径 | 用户不确定 → 按三条判据自查后请他确认，不靠口述 |
| 1 | **原始成绩数据在哪个目录？** 含不含学生级成绩榜、各校指标表、一分一段表、往次考试榜？ | 决定能不能做学生分层、能不能定分数线、能不能算环比 | 只有汇总表 → 砍掉③，告知"无法测上线与临界生" |
| 2 | **做 PPT 前有没有可参考的模板？** 要具体的 pptx 路径，不要"上次那个" | 有模板走复用工艺、无模板走自建工艺，两条路线的做法与风险完全不同 | 有 → 复制为母版；无 → 自建版式，先出 2 页样张确认；说不清 → 按无模板处理，并追问校名/校徽/主色 |
| 3 | **产物存到哪个文件夹？** 建议 `<工作区>/成绩分析_YYYYMMDD/` | 工作区根目录堆放会淹没交付物 | 用户未指定 → 按建议建目录，交付时报告路径 |
| 4 | **本次交付哪几件？** 校际对比 / 班级 / 学生分层 / PPT / 附录 | 决定 Phase 3 建哪几册 | 按模式默认全做 |
| 5 | **口径**（基准、名次分母、划线、赋分、聚合、前 N、边界） | 见 Phase 0；单校模式的基准与划线按 `exam-mode.md` 替换 | 逐项确认，不得默认 |

### 产物目录约定

```
成绩分析_YYYYMMDD/
├── 01_校际对比/      # 汇总工作簿（仅联考 A/B；单校不建此目录）
├── 02_班级分析/      # 班级工作簿
├── 03_学生分层/      # 分层工作簿
├── 04_汇报PPT/       # 成稿 pptx
└── _过程/            # scripts / run-log / 备份 / 中间数据
```

单校模式从 `02_` 起编号，或在说明页注明"01 因单校模式不适用"。交付物与过程产物分开放。`_过程/` 下保留每族脚本最新版，其余在 Phase 6 清理。目录一旦确定，全程不搬家——路径变更会让审计脚本全部失效。

详细话术、开工确认单模板、用户模糊回答的处理见 `references/intake.md`。

## Phase 0 口径锁定（阻塞，必须先做）

在动任何代码之前，把下列 7 项摆到用户面前逐项确认并记录成表。这 7 项就是本类任务全部的返工来源。

| # | 待锁口径 | 常见选项 | 默认建议 |
|---|---|---|---|
| 1 | 校际基准 | ①全部考生加权（指标表"整体"行）②参评校均分的简单平均 ③剔除本校 | ①。②的口径下分差会明显缩小，须在口径页说明二者方向一致、幅度不同 |
| 2 | 排名分母 | ①参评校总数 ②该科有考生的校数 | 按表内原名次列，并在脚注写明分母含义（缺考校会使分母变小） |
| 3 | 上线基数与划线 | ①本校考生基数 ②联考全体考生基数 ③官方公布名次 | 有官方名次一律用③；无官方值用②并按位次比对齐，且必须标注"推定值，不得对外引用" |
| 4 | 赋分科目处理 | ①赋分后 ②卷面原始分 ③两者并列 | ③。跨校对比只能用赋分后，卷面分仅用于校内环比 |
| 5 | 年级均分聚合 | ①按学生加权 ②各班均分算术平均 | 二者不可混用，须在两个交付物中各自写明。校际对比用①，班级横向比较用② |
| 6 | 前 N 名口径 | ①绝对名次含同分并列 ②按比例折算 | ①。须声明"含同分并列"以及各科考生池不同 |
| 7 | 交付物清单 | 分析工作簿 / 班级工作簿 / 学生分层工作簿 / PPT / 附录 | 先定清单再动手，避免算到一半发现要拆表 |

**锁定后写入项目记忆**，并在后续每一轮沟通中复用同一术语。用户中途改口径时，先列出"受影响页/表清单"再动手，不要直接改。

细节与话术见 `references/calibration.md`。

## Phase 1 数据体检（不做这一步必踩坑）

拿到数据包先跑体检，不要直接读表算数：

0. **模式复核**。`python3 scripts/reader.py --mode <数据包目录>` 起手判定（扫"各校/共性分析"类目录）；若有指标表，再用 `reader.count_schools(rows)` 数"学校"列去重得到的 N。N=0 或无外校目录即按形态 C（单校）执行，不要强行套联考口径。二者已在本机真实数据包上验证：联考包判 joint，9.22 单校包判 single。
1. **真实格式**。教育系统导出的表格常是 `扩展名 .xlsx、实为 OLE2 老式 .xls`。用 openpyxl 打开抛 `BadZipFile` 即为此症 → 换 `xlrd`。统一封装见 `scripts/reader.py` 的 `read_any()`。
2. **有效样本过滤**。三种过滤条件效果不同，选错会虚增人数：
   - 用"是否参与统计"列过滤（学生榜常有）；
   - 用"总分非空"过滤会漏掉占位 `0` 的缺考生；
   - **正确做法：以"整体排名为数字"为准**。真实案例中某生总分列写 `0`、排名列写 `-`，系统不计入，班额因此是 17 而非 18。
3. **赋分识别**。判断再选科目是赋分还是卷面：看**最低分**。赋分起点通常 30 分，若全部参评校（N 所，单校模式则看全校各班）该科最低分均 ≥30 且多校/多班恰为 30，则为赋分；对照首选科目（最低可至个位数）即可确认。判错会把赋分差当原始分差解读，量级差一倍。
4. **结构指纹**。记录每个工作表的"表头文字 + 列名序列 + 有效行数"，用列名而非列序号定位。数据源重生成时先比对指纹再取值。
5. **汇总行污染**。班级对比表常内嵌"年级""整体"汇总行，按班级聚合前必须剔除，否则均值池被污染。

完整陷阱库（12 条，含判别方法与处理）见 `references/data-pitfalls.md`。

## Phase 2 计算

按锁定口径实现，几个固定要求：

- **舍入统一 `ROUND_HALF_UP`**（`Decimal(str(x)).quantize(Decimal("0.01"))`）。Python 内置 `round()` 是银行家舍入，精确均值落在 `x.xx5` 时会差 0.01，与教务系统不一致。
- **参评校数 N 从数据取**，不写常量；名次 `x/N` 随当次数据变化；各科 N 可能不同。
- **加权合并**：`Σ(均分×人数)/Σ人数`；各科"整体"人数 ≠ 总分人数（如语文 8263、总分 8265），合并基准必须按各科实际人数加权。
- **跨方向合并**只用共同科目；首选科目（物理/历史）不可合并，必须分列。
- **上线定位**用一分一段表：由名次反查分数，注意一分一段累计人数与学生"整体排名"存在 9–26 人的系统偏移（含未参与排名者），但上线人数通常一致，须交叉验证。**单校模式无联考一分一段**，按 `exam-mode.md` 第四节的三种替代方案之一执行，并标注性质。
- **单校模式的基准替换**：联考基准 → 本校年级均分（分方向）；分差 → 与年级均分差 / 与上次考试差；超均率 → 得分率；名次 → 年级名次 `x/本校人数`。
- **学生分层**（潜力生/临界生）：分层依据用入口分或历次考试，每档给出人数、班级分布、距线差、达标次数；临界生区间要写清开闭区间（如 `−15（含）至 −10（不含）`）。

## Phase 3 Excel 产出

- **必须有一张"说明"工作表**，位于第 1 位。内容：交付物清单、每个工作表的口径、考试类型（联考/单校）、数据来源与时间、已知边界。真实案例中 80% 的用户质疑都终结于这张表。
- **第一册（校际对比）只在形态 A/B 建**；单校模式直接从第二册开始，说明页首行写明"本次无外校成绩，不含任何校际对比"。
- 两套口径并存时，在冲突表上方加**醒目警示条**（`FFE699` 填充、深红加粗），并写明"不可混引、不可相减"。
- 单科表统一在末尾加两列对照：联考模式为"与本校平均分差""与联考平均分差"；单校模式为"与年级平均分差""与上次考试差"。
- 数值格式两位小数；人数类强制整数（避免出现 `39.0`）。
- **修改已有工作簿时不要用 openpyxl 重存**：会丢图表与部分条件格式。用 `scripts/xlsx_patch.py` 直改写 `xl/worksheets/sheet*.xml`，其余 zip 条目按原 `date_time`/`compress_type` 字节复制。中文可能以 `&#NNNN;` 实体存于 inlineStr（无 sharedStrings），替换需"解码 → 精确比对旧文 → 重新实体编码"。

## Phase 4 PPT 产出

**先分支，再动手。** 有模板与无模板是两条完全不同的工艺，不可混用。

### 分支判断（Step 0 第 2 问的答案决定）

| 分支 | 条件 | 做法 | 风险点 |
|---|---|---|---|
| **A 有模板** | 用户给出上一次同类会议的 pptx 路径 | 复制该 pptx 为母版，继承 `slide_master` / `slide_layout` / 主题字体 / 配色，**只替换文字与表格**，不改几何与视觉语言 | 版式与内容量不匹配时（如原模板单表 8 行、本次 15 行）需拆表，不能缩字号硬塞 |
| **B 无模板** | 用户明确没有，或只有 PDF/截图/口头描述 | 按 `references/ppt-spec.md` 第五节"从零设计"自建整套视觉规范，**先出 2 页样张（封面 + 一张表格页）确认，再做剩余页** | 自建版式最容易被否；样张是唯一的低成本纠错点 |

判断不清时按 B 处理，并额外问三件事：学校全称与简称、有无校徽图片文件、学校是否有惯用主色。这三项决定封面与标题条。

### 页数结构

- 联考（A/B 形态）：`封面 1 + 章节页 4 + 正文 20 + 结束 1 + 口径页 1`
- 单校（C 形态）：`封面 1 + 章节页 4 + 正文 16 + 结束 1 + 口径页 2`，删掉"总分排名与联考分差"整章（含名次、分差、超均率三列），第一章改为"年级整体与环比"

### 每页固定四区块

**标题 + 右上口径说明（含参照值数值）+ 表格 + 结论**。参照值必须写在页面上，否则用户一定会问"这个差是跟谁比"。联考写"N 校该科均分"，单校写"年级该科均分"。

### 通用要求

- 数值两位小数；表格字号按内容自适应；结论框高度按剩余空间计算，不得越界。
- 单表超过 14 行必须拆成左右两表，不缩字号。
- 口径页至少覆盖：考试类型与可用范围、基准算法、分差与得分率定义、名次分母（N 或本校人数）、赋分说明、合成值说明、两套均分口径差异、划线性质（联考划线 / 校内模拟线）。
- 单校模式的结论不可出现"与联考差""全市排名"等表述，改用"与年级均分""与上次考试"。
- 改 pptx 文本**必须用 `paragraph.add_run()` 再替换 `rPr`**。用 lxml 把 `<a:r>` append 到段落末尾会落在 `<a:endParaRPr>` 之后，违反 DrawingML 子元素顺序，PowerPoint 渲染时整段不显示。

### 分支 A 的额外约束

- 不改母版配色与字体，即使你认为"换个颜色更好看"。
- 新增页必须复用已有 layout，不自建形状堆叠。
- 若模板页与被替换内容结构差异大（如原为图片页、本次要放 15 行表），改为复用最接近的表格 layout，不要在原图上盖表。

### 分支 B 的产出顺序

1. 确认三要素（校名、校徽、主色）；
2. 出封面样张 + 一张表格页样张，共 2 页；
3. 用户确认后批量生成正文，先做第 1 章再复制骨架做第 2–4 章；
4. 整稿渲染通读，按 `ppt-spec.md` 第九节清单逐项检查。

版式细则与从零设计规范见 `references/ppt-spec.md`。

## Phase 5 独立核对（不可省）

核对脚本**不得复用生成阶段的数据文件**（如 `ppt_data.json`），必须直接从原始 Excel 重算再比对。否则生成与核对同错，核对无效。

- 粒度：单元格级。数值按 `±0.005` 容差比；文字按去空格后精确比；"是/否""n/有效"按格式化后字符串比。
- 必须容忍并单列的三类差异（不是错误）：同分并列行序、`x.xx5` 边界 0.01、显示值相减与原值相减的 0.01 差。
- **结论文字也要核**。把每句结论里的关键量抽出来复算（分差、占比、人数、班级数），这是唯一能抓住"物理贡献率最低"这类错误的办法。
- 每轮数据变更后**全量重跑**，不做增量。真实项目单轮核对约 1.1 万项，跑一次比查三天便宜。
- 输出"项数 / 不符项 / 精度备注"三段式报告。

**单校模式没有外部锚点**（无 N 校指标表、无联考一分一段），改用六条内部恒等式核对：人数闭合、总分闭合、加权闭合、排名闭合、环比闭合、赋分闭合。逐条验法与容差见 `references/exam-mode.md` 第五节。

骨架见 `scripts/audit_scaffold.py` 与 `references/audit-method.md`。

- `run-log.md` 记录：每版成品的页数、`sha256`、数据源版本、逐页改动、复核项数、遗留问题。放在产物目录的 `_过程/` 下。
- 大改前备份到 `<产物目录>/_过程/备份/YYYY-MM-DD_HHMM_<原因>前/`，事后做**逐格 diff** 证明"只改了这几处"。
- 补丁脚本必须支持 `--dry-run`，且"旧文不匹配即报错退出"，禁止盲改。
- 交付后整理：删除渲染截图/单页文件/模板解包目录/一次性 diag 脚本，保留"每个脚本族的最新版"。

## 硬规则

1. **开工问询未完成，不读数据、不写代码**。考试类型、原始数据路径、参考模板、产物目录四项缺一不可。
2. **先判联考还是单校**，再决定做不做①。单校考试不得出现校际分差、联考名次、超均率。
3. **参评校数 N 由数据统计，不写死**；各科 N 可能不同；换考试重新取。
4. **PPT 先问模板**：有模板必须复用，不得自创视觉语言；无模板必须自建完整版式（按 `ppt-spec.md` 第五节），先出 2 页样张确认再批量生成。两种情况下都不许直接套用第三方通用模板。
5. 口径未锁定，不写计算代码。
6. 生成与核对不同源。
7. 不确定的数字不写进结论，写进"待确认"清单。
8. 任何"推定值"必须带"不得对外引用"标注；单校模式的分数线一律称"校内模拟线"。
9. 委派子代理写文件后，**必须回读磁盘校验**（真实事故：子代理报告"已写入 10 个 sheet"并给出完整数值，文件实为 4.8KB 空壳）。
10. 名次不等于全州/全省位次，参评校构成必须在口径页声明。
11. 产物目录一旦确定，全程不搬家。

## 脚本位置

本技能所有脚本以**技能目录**为基准，不在用户工作区：

```bash
python3 <技能目录>/scripts/selftest.py        # 装好后先自检
python3 <技能目录>/scripts/reader.py --mode <数据包目录>
```

复制或调用时不要硬编绝对路径；产物写入用户在 Step 0 指定的目录。
